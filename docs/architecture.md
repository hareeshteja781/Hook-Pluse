# Hook Pluse Architecture

## System Direction

Hook Pluse is an event-driven webhook platform with a FastAPI backend, PostgreSQL persistence, Redis Streams for asynchronous processing, a background worker, and a React dashboard.

## Phase Ownership

- Backend/API and persistence: Phases 3–6
- Frontend/dashboard: Phase 7
- Real-time updates: Phase 8
- Event inspection and replay: Phase 9
- Metrics and simulator: Phase 10
- Hardening and delivery pipeline: Phases 11–12

Detailed architecture decisions will be recorded as the implementation progresses.
